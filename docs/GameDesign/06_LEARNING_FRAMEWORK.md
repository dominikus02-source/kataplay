| Rentang Usia | Level | Durasi | Goal Akhir |

## LEVEL 1-20: FONIK & HURUF

### Tujuan Belajar

| Kompetensi | Target |
|-----------|--------|
| **Huruf** | Mengenal seluruh 26 huruf (kapital & kecil) |
| **Fonik** | Bunyi setiap huruf (bukan nama huruf) |
| **Menulis** | Tracing huruf (motorik halus) |
| **Kosakata** | 50+ kata 2-3 huruf |

### Kurikulum Detail

| Level | Huruf | Kata Baru | Skill |
|-------|-------|-----------|-------|
| 1 | A, B, C | ayam, bola, cokelat | Fonik A-B-C |
| 2 | D, E, F | daun, ekor, fanta | Fonik D-E-F |
| 3 | G, H, I | gajah, hujan, ikan | Fonik G-H-I |
| 4 | Review A-I | — | Review game |
| 5 | J, K, L | jambu, kucing, lampu | Fonik J-K-L |
| 6 | M, N, O | matahari, nanas, obat | Fonik M-N-O |
| 7 | P, Q, R | panda, queue, rusa | Fonik P-Q-R |
| 8 | Review A-R | — | Review game |
| 9 | S, T, U | sapu, topi, ular | Fonik S-T-U |
| 10 | V, W, X | vas, wortel, xilofon | Fonik V-W-X |
| 11 | Y, Z | yogurt, zebra | Fonik Y-Z |
| 12 | Review semua | — | Review game |
| 13 | Kapital vs kecil | — | Case recognition |
| 14 | Vokal a-i-u-e-o | — | Vokal focus |
| 15 | Konsonan | — | Konsonan focus |
| 16-18 | Kata 2 huruf | di, ke, ia, me, be | Blending |
| 19-20 | Kata 3 huruf | ibu, kakek, bibi | Word building |

### Assessment Level 20

Anak dapat:
- Menyebut bunyi 26 huruf
- Membedakan kapital & kecil
- Membaca 10 kata 3 huruf
- Menulis (tracing) namanya sendiri

## LEVEL 41-60: KALIMAT SEDERHANA

### Tujuan Belajar

| Kompetensi | Target |
|-----------|--------|
| **Struktur** | S-P-O (Subjek-Predikat-Objek) |
| **Kata kerja** | 30+ kata kerja dasar |
| **Kalimat (+/-/?)** | Positif, negatif, tanya |
| **Membaca** | Kalimat 5-8 kata |
| **Menulis** | Menulis kalimat pendek |

### Grammar Points

| Level | Fokus Grammar | Contoh |
|-------|--------------|--------|
| 41-43 | S-P (subjek + predikat) | "Kucing makan." |
| 44-46 | S-P-O | "Kucing makan ikan." |
| 47-49 | Kata depan: di, ke, dari | "Ikan di meja." |
| 50-52 | Kalimat negatif: tidak/bukan | "Kucing tidak makan." |
| 53-55 | Kalimat tanya: apa, siapa, di mana | "Apa yang kucing makan?" |
| 56-57 | Kata sifat: besar, kecil, cantik | "Kucing besar itu cantik." |
| 58-59 | Kata hubung: dan, atau, tetapi | "Kucing dan ikan." |
| 60 | Review | — |

## LEVEL 61-80: MEMBACA & MENULIS

### Tujuan Belajar

| Kompetensi | Target |
|-----------|--------|
| **Membaca** | Paragraf 3-5 kalimat |
| **Pemahaman** | Menjawab pertanyaan bacaan |
| **Menulis** | 3-4 kalimat tentang topik |
| **Kosakata** | 500+ kata |

### Reading Level Progression

| Level | Text Complexity | Length |
|-------|----------------|--------|
| 61-65 | 2 kalimat, kata familiar | 20-30 kata |
| 66-70 | 3 kalimat, 1 kata baru | 30-45 kata |
| 71-75 | 4 kalimat, 2 kata baru | 45-60 kata |
| 76-80 | 5 kalimat, 3 kata baru | 60-80 kata |

### Writing Prompts

| Level | Prompt |
|-------|--------|
| 61 | "Tulis 1 kalimat tentang hewan favoritmu." |
| 65 | "Tulis 2 kalimat tentang keluargamu." |
| 70 | "Ceritakan kegiatan hari ini (3 kalimat)." |
| 75 | "Deskripsikan temanmu (4 kalimat)." |
| 80 | "Buat cerita pendek bebas (5 kalimat)." |

## LEVEL 81-100: MAHIR

### Tujuan Belajar

| Kompetensi | Target |
|-----------|--------|
| **Membaca** | Cerita 100+ kata, buku anak |
| **Menulis** | Paragraf koheren (5-7 kalimat) |
| **Grammar** | Tenses, imbuhan (me-, ber-, ter-) |
| **Kosakata** | 1000+ kata |
| **Berbicara** | Menceritakan kembali cerita |

### Advanced Topics

| Level | Topik |
|-------|-------|
| 81-85 | Imbuhan me- (makan → memakan) |
| 86-88 | Imbuhan ber- (main → bermain) |
| 89-91 | Imbuhan ter- (besar → terbesar) |
| 92-94 | Kata ulang (buku-buku, jalan-jalan) |
| 95-96 | Sinonim & antonim |
| 97-98 | Peribahasa sederhana |
| 99-100 | Menulis cerita pendek orisinal |
