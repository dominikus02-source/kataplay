## ★ MVP MINI GAMES (Prioritas 1-5)

### MG1: Letter Pop ★

| Atribut | Detail |
|---------|--------|
| **Nama** | Letter Pop |
| **Kategori** | Huruf |
| **Usia** | 4-6 tahun |
| **Durasi** | 60 detik |
| **Tujuan** | Mengenal bunyi & bentuk huruf |
| **Gameplay** | Huruf-huruf melayang di layar. Zelby menyebut huruf. Anak harus mengetuk huruf yang benar. Setiap benar → pop animation + suara senang. Salah → huruf goyang + "coba lagi." |
| **Difficulty 1** | 3 pilihan huruf |
| **Difficulty 2** | 5 pilihan |
| **Difficulty 3** | 8 pilihan + timer 30s |
| **Reward** | 10 XP + 5 koin per benar |
| **Fokus belajar** | Fonik, recognition |

### MG2: Word Builder ★

| Atribut | Detail |
|---------|--------|
| **Nama** | Word Builder |
| **Kategori** | Kata |
| **Usia** | 5-8 tahun |
| **Durasi** | 90 detik |
| **Tujuan** | Menyusun kata dari huruf |
| **Gameplay** | Gambar muncul + huruf acak di bawah. Anak drag huruf ke kotak yang benar. Animasi gambar bergerak saat kata terbentuk. |
| **Difficulty 1** | Kata 3 huruf |
| **Difficulty 2** | Kata 4-5 huruf |
| **Difficulty 3** | Kata 6 huruf + bonus speed |
| **Reward** | 15 XP + 10 koin |
| **Fokus belajar** | Spelling, kosakata |

### MG3: Picture Match ★

| Atribut | Detail |
|---------|--------|
| **Nama** | Picture Match |
| **Kategori** | Visual |
| **Usia** | 4-7 tahun |
| **Durasi** | 60 detik |
| **Tujuan** | Menghubungkan kata dengan gambar |
| **Gameplay** | Grid kartu (4-12 pasang). Anak tap kartu untuk membuka. Cocokkan kata dengan gambar. UI ramah anak, kartu rounded, warna cerah. |
| **Difficulty 1** | 4 pasang (2×4 grid) |
| **Difficulty 2** | 6 pasang (3×4 grid) |
| **Difficulty 3** | 8 pasang (4×4 grid) |
| **Reward** | 10 XP + 5 koin |
| **Fokus belajar** | Kosakata, memori visual |

### MG4: Story Time ★

| Atribut | Detail |
|---------|--------|
| **Nama** | Story Time |
| **Kategori** | Cerita |
| **Usia** | 6-10 tahun |
| **Durasi** | 3-5 menit |
| **Tujuan** | Membaca pemahaman |
| **Gameplay** | Cerita pendek ilustrasi (3-5 slide). Setelah baca/dengar, anak jawab 3 pertanyaan pilihan ganda. Pertanyaan: "Apa yang terjadi?" "Siapa yang..." "Di mana..." |
| **Difficulty 1** | 2 kalimat, 2 pertanyaan |
| **Difficulty 2** | 4 kalimat, 3 pertanyaan |
| **Difficulty 3** | 6 kalimat, 4 pertanyaan |
| **Reward** | 30 XP + stiker eksklusif |
| **Fokus belajar** | Reading comprehension |

### MG5: Sound Safari ★

| Atribut | Detail |
|---------|--------|
| **Nama** | Sound Safari |
| **Kategori** | Audio |
| **Usia** | 4-7 tahun |
| **Durasi** | 60 detik |
| **Tujuan** | Mendengarkan bunyi dan menghubungkan dengan kata |
| **Gameplay** | Zelby mengucapkan kata. Anak memilih gambar yang sesuai dari 3-5 pilihan. Audio native speaker. Feedback visual + audio. |
| **Difficulty 1** | 3 pilihan |
| **Difficulty 2** | 4 pilihan |
| **Difficulty 3** | 5 pilihan + kata mirip (minum/mimpi) |
| **Reward** | 10 XP + 5 koin |
| **Fokus belajar** | Listening comprehension |
