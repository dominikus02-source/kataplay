# KATAPLAY — OFFICIAL EXPRESSION SHEET

**Semua Karakter — 10 Ekspresi Standar**

**Versi:** 1.0

## FORMAT EKSPRESI

Setiap ekspresi mencakup:
- **ASCII Art** — representasi visual
- **Deskripsi** — apa yang terjadi pada wajah
- **Kapan Digunakan** — konteks in-game
- **Animasi Notes** — timing & transisi
