# KATAPLAY — OFFICIAL ACTION SHEET

## FORMAT POSE

Setiap pose mencakup:
- **ASCII Art** — siluet dan gesture
- **Deskripsi** — detail pose
- **Loop Type** — one-shot atau looping
- **Kapan Digunakan** — konteks in-game
- **Animation Timing**
