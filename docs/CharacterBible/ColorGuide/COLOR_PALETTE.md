## 8. COLOR USAGE RULES

### DO ✅

| Aturan | Alasan |
|--------|--------|
| Gunakan Cream (#FFF8EC) sebagai latar utama | Hangat, ramah anak, tidak menyilaukan |
| Gunakan Zelby Green (#0F8B6F) untuk CTA utama | Warna brand, konsisten |
| Gunakan warna karakter di UI yang berhubungan | Zelby area → hijau, Hazel → ungu, Alby → amber |
| Gunakan warna-warna vibrant secukupnya | Anak suka warna cerah — tapi perlu white space |
| Pastikan teks selalu kontras dengan background | Accessibility |

### DON'T ❌

| Aturan | Alasan |
|--------|--------|
| Jangan gunakan warna gelap sebagai background utama | Suram, tidak anak-friendly |
| Jangan gunakan warna merah untuk "salah" terlalu mencolok | Anak bisa takut — gunakan dengan hati-hati |
| Jangan pakai gradien berlebihan | Terlihat murahan, tidak premium |
| Jangan gunakan warna neon | Menyakitkan mata, tidak nyaman |
| Jangan gunakan >3 warna brand dalam satu layar | Terlalu ramai, membingungkan |
